# Изменения

## 0.2.35 — 2026-10-23 (локальная разработка Rust ядра)

- Нативные build/preview перенесены в `src-tauri/src/engine`: Rust запускает официальный GUI-генератор, lint, SDK-упаковку и отдельную игру. Node worker принимает только генерацию исходников с уже подготовленным GUI.
- Таймауты, ограничение вывода, проверка traceback при exit 0 и Windows Job Objects для сборочных процессов. Никакого shell или управления мышью владельца.
- Пакет ищется только в новом каталоге текущей сборки. Старый ZIP в папке назначения не может дать ложный успех; повторный выпуск не перезаписывает прежний файл. Подпись Android сохраняет прежний постоянный ключ; её фактическая JDK/Android-приёмка ещё открыта.
- 322 JS/50 Rust/4 Sites, фактические EXE/UI Build, повторное открытие, камера/RPG, 6 игровых сценариев/40 утверждений, два обычных старта и отдельный native preview. Обычный preview сохраняет прежнюю настройку Ren’Py save-directory; в QA проверены одинаковая папка и постоянные данные между двумя сгенерированными заданиями. Подробности — `docs/RELEASE_0.2.35.md`.
- Это первый этап полного Rust-переноса, не готовый Rust-компилятор или завершённый production. Публичный релиз 0.2.34 не изменён.
