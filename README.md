# История

Русскоязычный настольный конструктор визуальных новелл на React, Electron и Ren'Py. Выпуск **0.1.1 — предварительная версия**, не завершённый профессиональный редактор. [Ограничения и аудит](docs/PRODUCT_AUDIT.md).

## Установка Windows

Скачайте `Istoriya-Setup-0.1.1-x64.exe` из [Releases](https://github.com/coolmorimer/istoriya-vn-creator/releases). Запустите установщик, выберите папку и при необходимости ярлык на рабочем столе. Требуется Windows 10/11 x64. Установка для текущего пользователя без прав администратора.

Редактор, Python и Ren'Py 8.5.3 входят в установщик; Node.js для использования не нужен. Удаление через «Установленные приложения» не удаляет проекты. Перед обновлением сохраняйте резервные копии. Установщик не подписан коммерческим сертификатом: Windows может предупредить о неизвестном издателе. Проверяйте источник загрузки и `SHA256SUMS.txt`.

Android требует настройки JDK 21, Android SDK и RAPT. Ключи подписи создаются локально и не включены в дистрибутив. Мобильная сборка на чистой машине не входит в проверенный сценарий выпуска.

## Возможности

- Библиотека проектов; новый проект начинается с пустой сцены.
- Главы, сцены, карты связей, переходы, переменные, условия и выборы.
- Ресурсы, персонажи с именованными спрайтами и выбором основного.
- Перемещение персонажей мышью и пропорциональный размер за углы рамки.
- Временная шкала: дорожки, масштабирование, перенос и подрезка поддерживаемых клипов.
- Настройки текста, импорт шрифтов, диалоги, музыка и звуки.
- Сохранение, Undo/Redo, импорт/экспорт проектов, генерация игр Ren'Py.

Ключевые кадры, полноценная камера, waveform и разрезание аудио с source-offset, ripple-edit и полный визуальный редактор игровых меню пока не реализованы. Проверка lint не заменяет прохождение игры. [Спрайты и трансформации](docs/SPRITES_AND_TRANSFORMS.md).

## Сборка из исходников

Нужны Windows, Node.js 22+ с npm, [Inno Setup 6](https://jrsoftware.org/isinfo.php) и официальный [Ren'Py SDK 8.5.3](https://www.renpy.org/release/8.5.3). Распакуйте SDK рядом с репозиторием в папку `renpy-8.5.3-sdk`.

```powershell
npm ci
node scripts/collect-notices.mjs
npm test
npm run desktop:dev
```

Установщик с проверками и сборкой:

```powershell
npm run installer
```

Результат: `release-installer/setup/`, рядом SHA-256. Из SDK исключаются временные сборки, журналы, сохранения, локальные настройки Android и ключи. Старые локальные папки `release-*` не являются актуальным релизом.

Web-разработка: `npm run dev -- --host 127.0.0.1 --port 4173`. Браузерная версия не имеет системной сборки игр без Electron. Проверки: `npm test`, `npm run build`, `npm run verify:runtime`.
