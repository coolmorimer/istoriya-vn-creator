# История

Русскоязычный настольный конструктор визуальных новелл на **Tauri/Rust, React и Ren'Py**. Версия **0.2.32 — проверяемая бета**, не заявление о выполнении всего ТЗ. Electron сохранён как резервная сборка. [План production](docs/PRODUCTION_PLAN.md) · [Проверки 0.2.32](docs/RELEASE_0.2.32.md) · [Матрица MVP](docs/MVP_ACCEPTANCE.md) · [Интерактивный движок](docs/ENGINE_SCOPE.md).

В свойствах озвучки и звука можно записать микрофон: явное разрешение, до2 минут, WAV, прослушивание/Undo и отмена без добавления черновика. Обработка локальная. Встроенное проигрывание поддерживает плавное начало музыки и затухание при остановке; физический микрофон/слышимая речь пока отдельно не приняты. `npm run verify:release` проверяет фактическую нативную сборку и игру; это не вся production-приёмка.

«Хранилище редактора» на главной/в настройках позволяет скопировать библиотеку и ресурсы на другой диск с проверкой файлов и явным возвратом. Компоновка и тестовые слоты переносятся по выбору; кэш и compiler temp создаются на новом диске. Исходная копия не удаляется и место автоматически не освобождается; внешние `.vnproject` остаются на своих местах. Недоступная папка не подменяется пустой библиотекой. Исправлены бесплатное применение после очистки требования вещи, несовпадение legacy-аудио в форме/проверке и сброс сворачивания глав. Подробности — в отчёте0.2.31.

«Диагностика редактора» находится на главной, в настройках и при ошибках. Можно скопировать техническую информацию или открыть папку журналов; при отказе буфера — выделить отчёт вручную. Тексты истории, медиа, имена проектов и полные пути в отчёт не включаются, ничего автоматически не отправляется. Журнал ограничен3×256 КиБ; отказ записи не блокирует сохранение проекта. В браузере журнал только в памяти. Подробные границы — в отчёте0.2.30.

Холст: настоящее «Вписать», масштаб1–800% (100% — исходные пиксели), колесо под курсором, рука/пробел/средняя кнопка для перемещения вида. В режиме руки работают стрелки; Ctrl+0 вписывает, Ctrl+1 возвращает исходный размер. «К выбранному слою» находит видимый объект за кадром. Навигация не меняет проект/Undo; перемещение и размер самого объекта сохраняются отдельно. Исправлены ручки, перекрывавшие центр маленького предмета на10%. На том же1000×700 окне кадр стал370 вместо199 CSS-пикселей по ширине — это удобство, не замер FPS.

Предметы добавляются отдельными слоями через «Сцены → Предмет». В свойствах задаются действия, инвентарь, ответ, говорящий, голос/SFX, условия и переходы; шаг «Осмотреть сцену» ждёт игрока. Озвучка реплики находится в свойствах текста, звук обычного шага — в «Добавить звук к действию». Подключаются готовые MP3/WAV/OGG, не синтез речи. В0.2.28 исправлена гонка автоподстановки имени предмета; недоступные записи теперь видны и не маскируются под «Без записи». Native-сценарий из пустого проекта и UI-built Windows-игра с Save/Load/Rollback проверены.

Главы сворачиваются, поиск находит сцены внутри них, «К текущей» возвращает выбранную сцену в дерево. Большая карта отрисовывает видимую область; поиск/Home/End переносят к далёкой сцене. Обе карты обходят карточки путями и подписями, сохраняют реальные игровые переходы и предупреждают о перекрытых портах. На500 сценах/999 связях warm-медиана открытия91,4 →123,2 мс: это стоимость исправленной маршрутизации, не заявленное ускорение. Проверены клики по линиям/подписям, Delete/Undo, обратные связи и петля; все координаты сохранены. Границы поиска и плотных схем — в отчёте0.2.28.

Ctrl+Shift+F / «Найти в проекте» открывает сцену, текст, реакцию предмета, спрайт, ресурс, инвентарь или изображение галереи. «Где используется» в библиотеке показывает все ссылки через поиск и страницы. Переход открывает точный шаг/инспектор и время старого монтажа, не меняя проект/Undo. Native500 сцен/1024 записи/509 использований и повторное открытие проверены; подробности и границы — в отчёте0.2.26.

## Установка Windows

Новая локальная сборка: `D:\Istoriya-Releases\0.2.32\Istoriya-Rust-Setup-0.2.32-x64.exe`. Рядом — технический portable-проект предметов/озвучки, Windows ZIP, SHA и QA. Она ещё не опубликована в GitHub Releases и не установлена автоматически; старые публичные установщики не содержат этих исправлений. Требуется Windows 10/11 x64. Установка для текущего пользователя без прав администратора. При отсутствии WebView2 установщик загрузит его через официальный Microsoft Bootstrapper; для этого нужен интернет. Проверьте свободное место и для приложения, и для выбранного профиля.

Редактор, Python и Ren'Py 8.5.3 входят в установщик; Node.js для использования не нужен. Удаление через «Установленные приложения» не удаляет проекты. Перед обновлением сохраняйте резервные копии. Установщик не подписан коммерческим сертификатом: Windows может предупредить о неизвестном издателе. Проверяйте источник загрузки и `SHA256SUMS.txt`.

Установка на D: сама по себе не переносит профиль с C:. После установки можно явно выбрать «Хранилище редактора» и выполнить проверенное копирование/переключение. Исходная системная папка остаётся для locator/резервной копии и должна быть доступна для записи; профиль владельца автоматически не перемещался.

Android требует настройки JDK 21, Android SDK и RAPT. Ключи подписи создаются локально и не включены в дистрибутив. Мобильная сборка на чистой машине не входит в проверенный сценарий выпуска.

## Возможности

- После сбоя — видимый выбор черновика/сохранённой версии с датой и фрагментом текста. Восстановление записывает проект и карточку библиотеки вместе; отказ диска не удаляет черновик. Можно закрыть окно без выбора или сохранить полную копию, явную копию со ссылками при пропавшем ресурсе, исходный повреждённый JSON. В Rust копии записываются нативно с обработкой отмены/ошибки, не через ненадёжную HTML-загрузку. [Проверенные аварийные сценарии0.2.23](docs/RELEASE_0.2.23.md).

- Поиск ресурсов по названию/исходному файлу, категории и прокрутка большой библиотеки без создания всех карточек. Клавиатура: стрелки, Home/End; «Где используется» ведёт к слою, реплике, герою, инвентарю или UI. На собственном native-наборе500 сцен/5000 шагов/5000 небольших PNG открытие библиотеки сократилось с6,7–8,3 сек. до183–254 мс; это не замер холодного старта или пиковой RAM. Все5000 ресурсов проверены по SHA в экспортированной игре. [Методика и границы0.2.22](docs/RELEASE_0.2.22.md).

- «Ресурсы → Проверить и восстановить файлы»: найти пропавшие изображения, записи и шрифты, выбрать отдельный файл или папку, явно разрешить совпадения имён и применить замену одним Undo. Имена, ID, реакции, положение и эмоции героя сохраняются; повреждённая управляемая копия восстанавливается с резервированием старых байтов. [Проверки и ограничения0.2.21](docs/RELEASE_0.2.21.md).

- «Предмет → Добавить реакцию»: единая отменяемая форма для осмотра, получения/применения вещи, имени/описания/иконки инвентаря, героя, озвучки/SFX, условий и перехода. Расходование выбирается явно; Cancel не оставляет объектов. [Сценарии и границы0.2.20](docs/RELEASE_0.2.20.md).

- В Rust-версии сохранённые изображения/голос/шрифты выдаются по запросу, а не как base64 всей библиотеки. Резервная копия материализует выбранный проект; при пропавшем файле доступна явная аварийная копия со ссылками. Проверены настоящий отказ записи, повтор сохранения и пустой новый проект при отсутствующем ресурсе старой истории. [Замер и ограничения 0.2.19](docs/RELEASE_0.2.19.md).

- В игровом инвентаре «Применить: …» показывает доступные цели текущей сцены. Задайте предмету реакцию с требованием вещи (без расхода) либо результатом её использования (с расходом); её условия, ответ, голос, звук и переход исполняются и из инвентаря, и при нажатии на сцене. [Проверки 0.2.18](docs/RELEASE_0.2.18.md).

- Библиотека проектов; новый проект начинается с пустой сцены.
- Новый выбор содержит два варианта без автоматической петли. «Создать сцену для варианта» делает пустую ветку и связывает её одним Undo; «Открыть сцену» ведёт к её кадрам. Условия/результаты доступны в раскрываемом блоке. Сквозной native-путь первой игры с Windows-сборкой кнопкой редактора проверен в0.2.17; обычные OS-диалоги выбора файлов/папок не автоматизировались.
- Встроенное тестовое прохождение: Save/Load в шесть отдельных слотов, возврат назад с восстановлением инвентаря/флагов, история, авто/пропуск и громкости. Это тестовые данные редактора, не игровые сохранения Ren'Py. [Проверки и ограничения](docs/RELEASE_0.2.15.md).
- «Предмет» над холстом или ПКМ → «Добавить предмет…»: изображение, название, осмотр/взятие в инвентарь и шаг осмотра в одной отменяемой операции. Здесь же «Звук и озвучка»: говорящий, MP3/WAV/OGG, прослушивание и громкость. Cancel/Undo убирает и новые записи. В свойствах — дополнительные реакции, условия/переходы, смена изображения и использование инвентаря. Озвученный ответ без текста ждёт продолжения перед переходом. В свойствах реплики — голос, в свойствах действия — SFX. [Проверки и границы](docs/RELEASE_0.2.16.md).
- Громкость каждой записи, повторяемые SFX и отдельная остановка музыки, эффектов, озвучки и фоновых звуков. «Интерфейс» редактирует главное меню, диалоговые зоны, выборы и быстрое меню: положение/размер, шрифты, изображения состояний кнопок. [Границы и проверки](docs/RELEASE_0.2.12.md).
- Все11 игровых экранов, включая паузу, Save/Load, настройки, историю, галерею и уведомления: визуальные области, сетки, шрифты/фоны/скины, доступные параметры игрока. Реальные действия проверены в экспортированной игре; встроенный просмотр кадров пока не заменяет всю игровую оболочку.
- «Сюжет → Инвентарь»: имена, описания, иконки, поиск и переход к местам использования. Составные условия «все / любое / наоборот», типизированные значения и несколько результатов выбора/реакции без кода. [Правила и совместимость schema4](docs/RELEASE_0.2.10.md).
- Главы, сцены, карты связей, переходы, переменные, условия и выборы.
- Правила выбора и переходы предметов прямо на картах сцен/глав; полноэкранный режим, масштаб под курсором и переход к назначению. [Проверки карт](docs/RELEASE_0.2.11.md).
- Ресурсы, персонажи с именованными спрайтами и выбором основного.
- Перемещение персонажей мышью и пропорциональный размер за углы рамки.
- Кадры сцены: последовательность шагов, накопленный холст, перестановка, копирование и редактирование текста. Секундная шкала сохранена для старых timed-сцен; конвертация выполняется явно.
- Регулируемые боковые панели и высота ленты кадров, сохранение компоновки, режим большого холста, свойства справа/слева, список слоёв выбранного кадра.
- Настройки текста, импорт шрифтов, диалоги, музыка и звуки.
- Сохранение, Undo/Redo, импорт/экспорт проектов, генерация игр Ren'Py.
- Резервная предыдущая версия локальных JSON, явные ошибки сохранения и аварийный экспорт при ошибке интерфейса.
- Перенос слоя персонажа на временную шкалу с сохранением трансформации и поддержкой Undo/Redo.

Ключевые кадры, полноценная камера, waveform и разрезание аудио с source-offset, ripple-edit и полный визуальный редактор игровых меню пока не реализованы. Проверка lint не заменяет прохождение игры. [Спрайты и трансформации](docs/SPRITES_AND_TRANSFORMS.md).

## Сборка из исходников

Нужны Windows, Rust stable/MSVC с Windows SDK, Node.js 22+ с npm, [Inno Setup 6](https://jrsoftware.org/isinfo.php) и официальный [Ren'Py SDK 8.5.3](https://www.renpy.org/release/8.5.3). Распакуйте SDK рядом с репозиторием в папку `renpy-8.5.3-sdk`.

```powershell
npm ci
node scripts/collect-notices.mjs
npm test
npm run desktop:dev
```

Установщик с проверками и сборкой:

```powershell
npm run installer
```

Результат: `release-rust/setup/`, рядом SHA-256. Из SDK исключаются временные сборки, журналы, сохранения, локальные настройки Android и ключи. Старые локальные папки `release-*` не являются актуальным релизом.

Web-разработка: `npm run dev -- --host 127.0.0.1 --port 4173`. Браузерная версия не имеет системной сборки игр без нативного приложения; крупные встроенные изображения хранятся в IndexedDB и ограничены квотой браузера. Rust-приложение хранит изображения в файлах. Проверки: `npm test`, `npm run native:test`, `npm run build`, `npm run verify:runtime`. На Windows `npm run verify:tea` проходит готовый ZIP примера на отдельном тестовом рабочем столе без управления пользовательской мышью.

Пример: `release-games/tea-with-goblins/Чай вместо подвига.vnproject` — переносимый послойный проект с графикой и звуком; рядом `chay_vmesto_podviga-1.0.2-win.zip`. Распакуйте его в новую папку, не поверх 1.0.0. Старый ZIP 1.0.0 содержит ошибку запуска gui7; его PASSED-отчёт был ложноположительным. Сборка исходников: `node scripts/build-tea-example.mjs`; проверка обычного старта: `npm run verify:tea:startup`, анимаций: `npm run verify:animations`. [Состав и границы проверки](examples/tea-with-goblins/README.md).
