# Две тропы — первая история

Короткий редактируемый пример с двумя концовками:3 сцены,3 эмоции Элиры,3 фона, музыка, появление героя и собственное диалоговое окно. Создан целиком через интерфейс редактора из пустого Full HD проекта. Это функциональный пример, не пятиминутная новелла.

В редакторе откройте `Две тропы — первая история.vnproject`. Все8 медиа встроены; дополнительные папки ресурсов и ручная правка кода не нужны. Фон и герой остаются независимыми изображениями. Озвучки актёром нет; музыка и рисунки переиспользованы из локального примера «Чай вместо подвига».

Для запуска готовой игры распакуйте `dve_tropy_pervaya_istoriya-0.1.0-win.zip` и откройте `.exe` внутри. Редактор/Python/SDK не требуются. Выбор ведёт либо к чаепитию, либо к рассвету; оба финала завершают игру. Quick Save/Load и откат проверены.

Редактор0.2.17 остаётся проверяемой бетой. Автоматические звуковые проверки не заменяют прослушивание музыки на вашем оборудовании. Лицензия DejaVu Sans приложена отдельно.
