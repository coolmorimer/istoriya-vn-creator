# Чай вместо подвига

## Скачать готовые проекты

В [релизе 0.2.34](https://github.com/coolmorimer/istoriya-vn-creator/releases/tag/v0.2.34) большие переносимые проекты вынесены из Git в файлы поставки:

- `tea-layered.vnproject` — послойная история 1.0.2 с эмоциями и диалогами.
- `tea-interactive.vnproject` — версия 1.1.0 с осмотром предметов и рецептом.
- `tea-adventure.vnproject` — отдельный короткий RPG-пример 0.2.34 с локациями, NPC, крафтом и учебным боем.
- `tea-adventure-win.zip` — готовая Windows-игра RPG-примера.

Откройте `.vnproject` через «Открыть проект» на главной. Изображения встроены; исходные абсолютные пути не нужны. В этой папке Git сохраняет сценарий, раскадровку, исходные ресурсы и генератор `project.mjs`. Маленький старый `Чай вместо подвига.vnproject` — текстовая постановка, не замена переносимому графическому примеру.

Далее сохранена история проверок версий 1.0.2/1.1.0. Указанные там локальные папки и архивы не обязательно включены в новую публичную поставку. Текущее руководство редактора — [PDF/HTML](https://github.com/coolmorimer/istoriya-vn-creator/releases/download/v0.2.34/Istoriya-0.2.34-Manual.zip).

## Интерактивная версия 1.1.0

Для редактора0.2.9+ добавлен отдельный `Чай вместо подвига — интерактивный проект.vnproject`. Прежний послойный пример и ZIP1.0.2 не заменены. В сцене «Самая опасная чашка» можно осмотреть стол/сервиз и попросить у Брога рецепт: он попадает в инвентарь и открывает продолжение. Настройки доступны в свойствах предметов и шаге «Осмотреть сцену». Голосовых записей в этой версии нет; записанную озвучку можно загрузить в реплики/ответы. Подробные проверки: `docs/RELEASE_0.2.9.md`.

## Исходная послойная версия 1.0.2

В поставке откройте `Чай вместо подвига.vnproject` через «Открыть проект». В исходниках его копия называется `Чай вместо подвига — послойный проект.vnproject`. Windows-игра — `chay_vmesto_podviga-1.0.2-win.zip`: распакуйте в новую папку, не поверх 1.0.0. Старый ZIP 1.0.0 неисправен (`gui7`). `layers-png.zip` содержит отдельные PNG. Все 20 ресурсов встроены в проект: абсолютные пути к исходным картинкам не нужны.

9 сцен, 2 главы, 2 выбора и 4 сочетания ветвей. Пример рассчитан примерно на пять минут спокойного чтения; точная длительность зависит от игрока. Внутренние сцены состоят из пустого интерьера, трёх персонажей, стола и чайного набора. Выберите «Слои» справа, затем нужный слой: его положение, размеры, порядок и прозрачность редактируются независимо. «Предмет» над холстом импортирует новый PNG. Фон настраивается отдельно.

Персонажи используют именованные эмоции, перемещение и анимационные действия. В редакторе 0.2.6 анимация сохраняет текущую эмоцию и размер, проигрывается в preview и ждёт завершения перед следующим шагом последовательной сцены. Предметные слои пока статичны в пределах сцены: пошаговые предметные анимации ещё не добавлены. Исходный текстовый проект сохранён рядом без замены.

Графика и спецификации запросов: [ASSET_PROMPTS.md](ASSET_PROMPTS.md). Сценарий: [SCENARIO.md](SCENARIO.md).

Проверены ветви модели, ресурсы, импорт/повторное открытие в headless Chromium, сохранение и Windows-экспорт из Rust EXE. 15 октября EXE 1.0.2 дошёл до главного меню при обычном запуске без аргументов и без Ren'Py test command. Затем прошёл все четыре сочетания ветвей и отдельный сценарий Save/Load/Rollback/истории: 5 сценариев и 14 утверждений, **без исключений в журнале**. Проверены отдельные слои и фактические границы стола в движке. Запуск — на отдельном тестовом рабочем столе без управления пользовательской мышью; QA-код добавляется только в временную копию ZIP. Команды: `npm run verify:tea:startup`, `npm run verify:tea`. Дополнительная изолированная проверка анимаций — `npm run verify:animations`: 9 сценариев и 90 утверждений.

В папке поставки `QA/1.0.2/` сохранены результаты и журналы нового запуска. Прежние зелёные отчёты 1.0.0 отозваны: тестовый движок продолжил работу после init-ошибки. Звук запускался через dummy-драйвер и не прослушивался. Это не проверка всех возможностей редактора: предметы статичны внутри сцены, персонажи используют стоячие позы, чистая Windows и разные DPI ещё не приняты. Подробности: `docs/RELEASE_0.2.6.md`.
