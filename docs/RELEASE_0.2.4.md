# 0.2.4 — послойная сцена в настоящей игре

**Отозвана оценка успешного запуска.** 15 октября пользователь обнаружил `ModuleNotFoundError: gui7` при обычном запуске ZIP 1.0.0. Ошибка присутствовала и в QA-журналах ниже: Ren'Py восстановился после неё и продолжил тесты до PASSED. Эти прогоны доказывают только исполнение последующих тестов после восстановления, но **не исправный автономный запуск**. Исправление и новая, более строгая проверка — в RELEASE_0.2.5.md. Старый установщик/игру не используйте для новой поставки.

Локальная бета от 15 октября 2026. Полный production-MVP ещё не принят. Этот выпуск исправляет экспорт геометрии и добавляет воспроизводимую проверку готового Windows EXE.

## Что исправлено

Фон, три персонажа, стол и чайный набор остаются независимыми слоями переносимого проекта «Чай вместо подвига». Стол/набор имеют собственные PNG с alpha, положение, размер, порядок, прозрачность, блокировку и видимость. Это не единый готовый фон.

Настоящий рендер выявил две ошибки, которые не были видны в проверках строк компилятора: `rotate=0` при стандартном `rotate_pad=True` создавал лишнюю квадратную рамку и смещал стол вверх; целые `0`/`1` в относительных координатах Ren'Py означали пиксели. Общие генераторы теперь явно выводят float-координаты, `rotate_pad=False`, `transform_anchor=True`. Предметы поворачиваются вокруг нижнего центра и в редакторе, и в игре; фон — вокруг центра. Исправлено также нижнее выравнивание текста.

Семантика подтверждается [официальной документацией трансформаций Ren'Py](https://www.renpy.org/doc/html/transform_properties.html); фактические координаты проверены в работающем движке.

## Воспроизведение runtime-проверки

На Windows после сборки примера выполнить `npm run verify:tea`. Сценарий создаёт новую временную копию, использует [Ren'Py testcases](https://www.renpy.org/doc/html/testcases.html), требует явного PASSED и полного числа ожидаемых сценариев. Результаты не подменяются успешным exit-кодом.

Вспомогательный процесс использует отдельный [Windows desktop](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-createdesktopw) и Job Object с завершением дочерних процессов при закрытии. Он не переключает input desktop и не вызывает OS mouse/keyboard injection. Рендер — ANGLE/Direct3D11 на текущей машине; аудио — dummy. Это изоляция окон для доверенной игры, **не security sandbox**.

## Оставшиеся границы

Звук не прослушивался. Проверка Save/Load не охватывает все timed-сцены, типы переменных, галерею и эффекты. Нет приёмки чистой Windows, обновления/отката, всех DPI или других платформ. Все анимационные пресеты ещё не проверены отдельно. Предметные слои пока статичны внутри сцены; настоящие сидячие позы не нарисованы. JS-компилятор всё ещё работает через встроенный Node worker — полного Rust-порта компилятора нет. Общая приёмка ТЗ продолжается по `docs/PRODUCTION_PLAN.md`.

Impeccable использован для согласования точки поворота предмета с прямым редактированием на холсте; общий визуальный стиль и компоновка не менялись.
