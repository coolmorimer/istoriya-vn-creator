## Реализация

Один `StoryDestinationField`/`storyDestinations` используется для развилок, обычных переходов, обеих веток условия, свойств/создания реакций предмета, обоих редакторов карты, входной/исходной сцены главы и перехода в предпросмотре. Главы и сцены — отдельные типы значения. Выбор сцены очищает соответствующий chapter override; выбор главы сохраняет привязку к её актуальному входу. Map APIs понимают типизированные значения и прежние строковые tokens. В существующем project/runtime формате нет второй системы переходов.

Список следует фактическому порядку глав/сцен, показывает контекст главы, ищет название/номер/главу/описание, нормализует регистр и ё/е. Цельная фраза ранжируется выше случайных совпадений: «Глава 10» не теряется среди сцен1.10. Это не fuzzy-поиск и не глобальный полнотекстовый поиск реплик. На странице смонтировано не более8 options; страницы и Home/End/стрелки/Enter дают доступ ко всем. Отмена/Escape не меняет проект. Поиск не записывается как авторское изменение.

Пустую главу выбрать нельзя. Отсутствующая ссылка видима до явной замены; первое значение не подставляется автоматически. Entry/source picker ограничен своей главой. Скрытые/удалённые свойства JavaScript prototype не считаются сценами; реально существующий собственный ID с таким именем сохраняет поддержку. Входящая сцена с буквальным ID `chapter:a` не путается с главойa в типизированном API.

Impeccable использован для единого компактного управления в существующей graphite/violet теме: список раскрывается по запросу, сохраняет контекст главы, имеет внутреннюю прокрутку и читаемое поле поиска. Визуальные раунды1440×940/1000×700 ограничены первичным и подтверждением; последний дополнительный rebuild исправлял функциональные React keys, не продолжал полировку.

## Исследованные ориентиры

- [Twine: Navigating the Story Map](https://twinery.org/reference/en/editing-stories/navigating.html) — поиск перехода и выбор результата клавиатурой. Заимствована идея быстрого поиска, не код и не требование писать `[[links]]`.
- [Godot4.6: Default editor shortcuts](https://docs.godotengine.org/en/4.6/tutorials/editor/default_key_mapping.html) — отдельный Quick Open Scene. Здесь улучшен конкретный выбор назначения/preview; глобальная команда Quick Open пока не добавлена.
- [WAI-ARIA APG: Combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) — combobox/listbox, active descendant и отмена без изменения выбранного значения. Это ориентир реализации, не заявление о проведённой NVDA/JAWS-приёмке.
