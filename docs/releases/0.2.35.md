# История 0.2.35

Бета для Windows 10/11 x64. Сборка от 23 октября 2026. Основное изменение — нативный конвейер сборки и отдельного предпросмотра на Rust. Авторский интерфейс и формат проектов 8 сохранены.

## Что изменилось

- Rust запускает официальный генератор игрового GUI, проверку сценария, упаковку и отдельную игру. Node временно остаётся генератором исходников.
- Ошибка runtime отменяет успех даже при коде процесса 0. Есть таймауты, ограничение журналов и контроль дочерних сборочных процессов.
- Пакет берётся только из текущей сборки. Предыдущий ZIP не подменяет результат и не перезаписывается.
- Отдельный предпросмотр сохраняет прежнее расположение игровых сохранений, а не переносит их во временный каталог компилятора.

Сцены и слои, эмоции персонажей, камера, ключевые кадры, инвентарь, NPC, крафт и игровые правила версии 0.2.34 остаются доступны. Это ещё не полный Rust-компилятор и не собственный Rust-проигрыватель.

## Установка и первая история

1. В старом редакторе экспортируйте важные проекты в переносимые `.vnproject`. Закройте редактор.
2. Скачайте установщик и сравните его SHA-256 с `SHA256SUMS.txt`. Файл не подписан сертификатом.
3. Запустите установщик. По умолчанию установка — для текущего пользователя без прав администратора. Если нет WebView2, для загрузки этого компонента потребуется интернет.
4. Откройте «Историю». «Новый проект» создаёт пустую историю; «Открыть проект» импортирует `.vnproject`.
5. В «Сценах» добавьте фон, персонажа со спрайтом и реплику. У каждого шага на холсте — накопленное состояние сцены.
6. Добавьте выбор и назначьте реальные сцены назначения. Проверьте ветви через «Запустить».
7. Нажмите «Собрать игру» → Windows. Передавайте весь ZIP или распакованную папку игры, а не один EXE.

Для примера откройте `tea-adventure.vnproject`. Руководство распакуйте и откройте PDF либо HTML локально; интернет для чтения не нужен. [Установка и восстановление данных](https://github.com/coolmorimer/istoriya-vn-creator/blob/v0.2.35/docs/INSTALL.md).

## Проверки и ограничения

Локально: 322 JS, 50 Rust и 4 Sites-теста; ESLint/Vite; совпадение 31 runtime-модуля. В настоящих играх из EXE — шесть сценариев и 40 утверждений, включая Save/Load/Rollback, RPG и камеру. Отдельно — два обычных запуска, UI Build, пустые проекты, повторное открытие и два native preview с постоянными данными. [Технический отчёт](https://github.com/coolmorimer/istoriya-vn-creator/blob/v0.2.35/docs/RELEASE_0.2.35.md).

Чистая Windows, установка/обновление, слышимое качество записи и Android не прошли отдельную приёмку. GitHub Actions не засчитывается как успешная проверка. Временные папки отдельного preview пока остаются на диске. Полная production-матрица и перенос игрового runtime на Rust продолжаются. Релиз 0.2.34 не заменяется.
