# История 0.2.37 бета для Windows

Русскоязычный конструктор визуальных новелл и 2D-приключений без программирования. Этот выпуск продолжает перенос ядра на Rust и включает изменения жизненного цикла предпросмотра из локальной версии 0.2.36.

## Что изменилось

- Rust проверяет структуру проекта до запуска сборки или отдельного предпросмотра. Ошибка указывает сцену, шаг и проблемное поле.
- Независимое ядро `istoriya-core` сохраняет исходные поля документа, включая старые форматы 1–8, пользовательские расширения и координаты за границами сцены.
- Документ передаётся генератору с проверкой длины и SHA-256. Даже изменение той же длины приводит к отказу, а не к сборке другого содержимого.
- Временный проект отдельного просмотра удаляется только после подтверждённого выхода игры. Основные сохранения сохраняются; дополнительное зеркало `game/saves` переносится за пределы временного кэша. Неизвестные или неоднозначные аварийные каталоги не удаляются.
- Повторная сборка создаёт новый игровой пакет без перезаписи предыдущего.

## Установка и начало работы

1. Нужны Windows 10/11 x64 и WebView2. При его отсутствии установщик загружает компонент Microsoft через интернет.
2. Перед обновлением экспортируйте важные проекты в переносимые `.vnproject` и закройте редактор.
3. Скачайте установщик и сравните SHA-256 со строкой в `SHA256SUMS.txt`. Сам установщик пока не подписан цифровым сертификатом.
4. Запустите установщик. По умолчанию установка выполняется для текущего пользователя без прав администратора.
5. Откройте «Историю» через меню «Пуск». «Новый проект» создаёт пустую историю; демонстрационные материалы автоматически не добавляются.
6. Для примера выберите «Открыть проект» и укажите `tea-adventure.vnproject`. ZIP с игрой предназначен для прохождения, не для редактирования.
7. В своей истории добавьте фон, персонажа со спрайтом, текст и выбор. Проверьте через «Запустить», затем «Собрать игру» → Windows.

## Проверка и ограничения

327 JS-тестов, 10 тестов чистого Rust-ядра, 69 тестов нативного приложения, 4 Sites-теста. Общий корпус из 1320 документов сравнивает Rust с прежним JS-валидатором: 305 приняты без изменения JSON, 1015 отклонены; отдельно проверены 11 точных адресов ошибок. Фактические прогоны EXE и готовых игр — в [отчёте версии](../RELEASE_0.2.37.md).

Это бета, не завершённый собственный Rust-движок. Генерация игровых исходников ещё частично на JavaScript, игровой runtime — Ren’Py. Полная ссылочная проверка и миграции пока не перенесены в Rust. Установка и обновление на чистой Windows, Android, все DPI/устройства и слышимое качество записи остаются отдельными проверками. GitHub Actions не засчитывается как пройденная приёмка.
