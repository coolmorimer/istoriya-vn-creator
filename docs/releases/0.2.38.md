# История 0.2.38 бета для Windows

Конструктор визуальных новелл и 2D-приключений без программирования. Главные изменения выпуска — согласованные переходы между главами и сценами, сохранение сцен вне глав и навигационный план на Rust.

## Что изменилось

- Начало игры учитывает выбранный вход первой непустой главы, а не первую карточку. Карта, предпросмотр и Windows-экспорт используют одинаковый порядок.
- Свободные сцены не присоединяются автоматически к первой главе при импорте. Дерево показывает их в группе «Вне глав»; поиск и клавиатурная навигация работают и для этой группы.
- Принадлежность сцены можно назначить или снять на карте, с Undo/Redo. Перенос входной сцены не оставляет битый вход в прежней главе. «Упорядочить» включает свободные сцены и отменяется.
- Rust проверяет входы и назначения переходов до запуска SDK. Удалённая сцена, пустая обязательная ссылка или неверный вход дают адресную ошибку. Незавершённый черновик можно сохранить.
- Генератор получает проверенный Rust-план с контролем длины и SHA-256 вместо повторного разрешения переходов в JavaScript.
- Сохранены изменения 0.2.37: структурная проверка документа, очистка подтверждённых временных просмотров после выхода игры и сохранение игровых данных отдельно от кэша.

## Скачать и установить

1. Нужны Windows 10/11 x64 и WebView2. Если компонента нет, установщик загрузит его через интернет. SDK и Node runtime уже включены; Rust/Python отдельно не нужны.
2. Перед обновлением экспортируйте важные истории в `.vnproject`, сохраните копии отдельно и закройте редактор.
3. Скачайте `Istoriya-Rust-Setup-0.2.38-x64.exe` и сравните SHA-256 со строкой в `SHA256SUMS.txt`. Установщик не подписан цифровым сертификатом.
4. Запустите установщик. По умолчанию он устанавливает программу для текущего пользователя без прав администратора. Откройте «Историю» через меню «Пуск».
5. «Новый проект» создаёт пустую историю без демонстрационных персонажей, изображений и диалогов. Для примера выберите «Открыть проект» и файл `tea-adventure.vnproject`.

[Подробная установка, резервная копия и диагностика](../INSTALL.md).

## Работа с главами и сценами

1. Откройте «Сюжет» и карту глав или сцен. Колесо меняет масштаб относительно курсора; «Показать всё» возвращает обзор. Для большой схемы раскройте карту на весь экран.
2. Выберите сцену на карте. В поле «Глава» назначьте главу или «Вне глав». Это меняет реальное членство, а не только расположение карточки. Отмена и повтор работают через Undo/Redo.
3. Для начала главы задайте её входную сцену из этой же главы. Метка «Начало игры» относится ко всей истории и показана у входа первой непустой главы.
4. Для выбора, условия или реакции предмета укажите назначение через общий список: конкретную сцену либо главу. Ссылка на главу следует за изменением её входа; ссылка на сцену остаётся точной.
5. Свободная сцена остаётся в «Вне глав» после сохранения и повторного открытия. Для её прямого посещения назначьте переход. Если нет явного перехода, продолжение следует порядку глав, затем свободных сцен по стабильному порядку их ID, не расположению карточек.
6. «Упорядочить» раскладывает все сцены, включая свободные. Чтобы вернуть прежние координаты, выполните Undo. Масштаб и «Показать всё» не являются изменениями истории.
7. Проверьте обе ветви через «Запустить», сохраните игру, загрузите её и только затем нажмите «Собрать игру» → Windows. Ошибку ссылки исправляйте в указанной сцене/шаге; удаление проекта или профиля не требуется.

Исходники скачиваются через Git/Source code, установщик — через Assets.

## Проверки и ограничения

Принятый EXE: 337 JS-тестов, 22 теста Rust-ядра, 70 нативных Rust-тестов и 4 Sites-теста. Сравнены 1320 структурных документов и 424 проекта переходов с 7039 разрешёнными связями. В готовых играх выполнены 7 сценариев, 48 утверждений и 2 обычных запуска. Проверены фактическая кнопка сборки, пустые проекты, повторное открытие, принадлежность сцен, клавиатура, Undo/Redo и два отдельных просмотра с сохранением данных.

Это бета. Генерация исходников ещё частично на JavaScript, игровой runtime — Ren’Py; собственный Rust-проигрыватель не готов. Установка и обновление на чистой Windows, Android, все DPI/физические устройства и слышимое качество записи не приняты. GitHub Actions не засчитывается как успешная проверка.
