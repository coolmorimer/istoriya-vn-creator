# История 0.2.34

Бета для Windows x64. Сборка приложения — 19 октября 2026; подготовка публичной поставки — 21 октября 2026.

## Главное

- Игровой мир без кода: здоровье, опыт, уровни, навыки, крафт, локации, NPC и ограниченный пошаговый бой.
- Игровая 2D-камера, редактируемые ключевые кадры фона, героя и предмета, готовые движения и пять интерполяций.
- Регулируемые и открепляемые панели внутри основного окна.
- Явный импорт готового набора: три взрослых героя, восемь эмоций, два фона и отдельные предметы. Новый проект остаётся пустым.
- Руководство PDF/HTML: 39 разделов, 71 страница PDF, 29 реальных скриншотов.

## Установить и начать

1. Экспортируйте важные проекты в переносимые `.vnproject` и закройте редактор.
2. Скачайте установщик, при необходимости сравните SHA-256 и запустите его. Windows 10/11 x64; если WebView2 отсутствует, для установки этого компонента нужен интернет.
3. Откройте «Историю». «Новый проект» создаёт пустую историю, «Открыть проект» импортирует скачанный `.vnproject`.
4. Для RPG-примера откройте `tea-adventure.vnproject` и нажмите «Запустить». Для собственного набора — «Сюжет → Игровой мир → Готовые наборы».
5. После проверки ветвей нажмите «Собрать игру» → Windows. Готовую игру передавайте целой распакованной папкой или ZIP, а не одним EXE.

Установщик не подписан. Загрузка из GitHub и контрольная сумма позволяют сверить файл, но не заменяют цифровую подпись. Подробности: [установка](https://github.com/coolmorimer/istoriya-vn-creator/blob/main/docs/INSTALL.md), [инструкция](https://github.com/coolmorimer/istoriya-vn-creator/releases/download/v0.2.34/Istoriya-0.2.34-Manual.zip).

## Проверки и ограничения

Для принятой локальной сборки: 319 JS, 37 Rust, 4 Sites, ESLint/Vite, совпадение 31 runtime-модуля по SHA. В играх из EXE — семь сценариев с 71 утверждением; отдельно три обычных старта без тестового режима. Проверены пустой проект, импорт, Undo/Redo, сохранение/повторное открытие, камера, взаимодействия, NPC, крафт, бой и Save/Load/Rollback. [Полный отчёт](https://github.com/coolmorimer/istoriya-vn-creator/blob/main/docs/RELEASE_0.2.34.md).

Проверка установки/обновления на чистой Windows, все физические DPI/устройства, слышимое качество микрофона и Android ещё не приняты. Это не универсальный 3D/action-движок, не полный Rust-компилятор и не завершение всей production-матрицы. RPG-пример короткий; пяти минут нового сценария он не обещает. Полные локальные QA-профили и пользовательские данные в публичную поставку не включены.
