# Игровой мир — incumbent extension

Режим Operate. Это расширение существующего графитового редактора, не новый визуальный мир и не переоформление остальных экранов. Корневые PRODUCT.md/DESIGN.md отсутствовали до работы; их не создаём в качестве побочного исправления.

THESIS: автор задаёт игровые системы в именованных формах, а не пишет скрипты. Одни определения используются выбором, предметами, картой, предпросмотром и экспортом.

OWN-WORLD: графитовые поверхности, фиолетовые действия, plum-выделение, существующие Manrope/Phosphor и общие поля. Готовый аниме-набор использует исходные послойные изображения с происхождением.

STORY: включить системы → добавить определения → поставить игровой шаг → пройти → собрать. Готовый набор добавляется явно и целиком отменяется; создание нового проекта не заполняет его демо.

FIRST VIEWPORT: «Сюжет → Игровой мир», компактная полоса разделов, список определений слева и форма справа. Карта локаций и рецепт показывают действующие связи. Ошибки и неполные записи видны, но авторский черновик можно сохранить.

FORM: code-led extension без смены мира; seed/comp round неприменимы. Действующая визуальная правда — `design/reference-main-ui.png` и соседний InventoryWorkspace.

FINISH: независимая проверка актуальных desktop/compact снимков, её фактический вердикт и сравнение с incumbent. Проверки EXE/игры и их ограничения записываются отдельно. Глобальные дизайн-файлы не выдумываются; новых иллюстраций эта итерация не производит.
