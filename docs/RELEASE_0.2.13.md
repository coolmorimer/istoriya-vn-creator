# 0.2.13 — один визуальный редактор для всех игровых экранов

Локальная проверяемая бета от15 октября2026. Полный production-MVP **не объявляется завершённым**. Актуальная матрица всех36 обязательных пунктов, единого сценария и дополнительных требований — MVP_ACCEPTANCE.md.

## Изменения

В «Интерфейс → Экран игры» выбирается один из11 экранов: главное меню, диалог, выборы, быстрое меню, пауза, сохранение, загрузка, настройки, история, галерея, уведомления. Справа контекстные свойства; области можно перемещать/масштабировать на холсте и задавать числами. Сохранены шрифты/импорт TTF/OTF, фоны и изображения состояний кнопок, Undo/Redo.

- **Пауза**: реальные переходы к Save/Load/Settings/History/Gallery/MainMenu/Quit и возврат в игру. Escape открывает настроенную паузу.
- **Save/Load**: независимые сетки/области, количество строк/колонок, настоящие слоты, миниатюра, дата и время прохождения; страницы, auto/quick, удаление через штатное действие.
- **Настройки**: автор выбирает доступные громкости, скорость текста/автоперехода, режим экрана/размер окна, режимы пропуска. В игре используются настоящие Preference/BarValue, не декоративные ползунки.
- **История**: `_history_list` с именами/текстом, прокрутка и собственный шрифт/область.
- **Галерея**: сетка разделов, размеры/отступы карточек, подпись и пользовательская картинка закрытого изображения. Нажатие закрытой карточки недоступно; после соответствующего CG используется persistent unlock и настоящий viewer.
- **Уведомления**: фон/шрифт/область/непрозрачность/таймер. Квадратные и фигурные скобки в уведомлениях и названиях галереи показываются буквально, не удваиваются.
- Неверные сетки/параметры/ID и скрытая кнопка выхода блокируют экспорт. Из ошибки проверки можно перейти к нужному экрану. Неактивная полоса прокрутки скрывается, если всё содержимое помещается.
- Обычные подтверждения загрузки, перезаписи, удаления и выхода переведены на русский. Предупреждение о доверии внешнему сохранению переведено без отключения защиты.

Impeccable использован для сохранения текущей графитово-фиолетовой оболочки, контекстного инспектора и одной понятной точки выбора экрана вместо11 вкладок. Исследование официальных примеров: [TyranoBuilder UI](https://tyranobuilder.com/tutorials/more/customize-the-user-interface), [Ren'Py screens](https://www.renpy.org/doc/html/screen_special.html), [действия сохранений/настроек](https://www.renpy.org/doc/html/screen_actions.html). Исходный код этих редакторов не копировался.

Schema6/layout2. Старые schema1–5 читаются. Старые дополнительные экраны сохраняют стандартное оформление до явной правки; ранее настроенные четыре экрана не сбрасываются. Новый проект остаётся пустым по ресурсам/героям/предметам/сценарию. Подписи «Образец сохранения» в авторском макете — образцы для компоновки, не данные игрока.
