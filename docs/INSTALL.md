# Установка Истории

Версия 0.2.38 предназначена для Windows 10/11 x64. Для работы нужен WebView2. Ren’Py, Node runtime и ресурсы редактора включены в установщик; отдельно ставить Python, Rust или инструменты разработчика не нужно.

## Скачать и проверить

Откройте [релиз v0.2.38](https://github.com/coolmorimer/istoriya-vn-creator/releases/tag/v0.2.38) и скачайте `Istoriya-Rust-Setup-0.2.38-x64.exe`. Не используйте старые архивы из промежуточных сборок.

Установщик не подписан цифровым сертификатом. Предупреждение Windows не означает успешную проверку файла: сначала убедитесь, что он скачан из указанного репозитория. При необходимости сравните SHA-256:

```powershell
Get-FileHash ./Istoriya-Rust-Setup-0.2.38-x64.exe -Algorithm SHA256
```

Сравните результат со строкой этого файла в `SHA256SUMS.txt` из того же релиза. Контрольные суммы предыдущих версий не подходят к 0.2.38.

## Установить

1. Закройте запущенный редактор.
2. Запустите установщик. По умолчанию он устанавливает приложение в `%LOCALAPPDATA%\Programs\Istoriya` для текущего пользователя.
3. При отсутствии WebView2 потребуется интернет для его загрузки. Если загрузка не удалась, установщик сообщает об ошибке; повторите после восстановления подключения.
4. При желании включите создание ярлыка. После завершения откройте «Историю».

Не запускайте приложение прямо из папки SDK или сборочного кэша. В установленной папке запускается `История.exe` вместе с соседними компонентами.

## Обновить безопасно

Перед обновлением откройте важные проекты и экспортируйте их переносимые копии `.vnproject`. Храните копии отдельно от папки программы. При экспорте с ошибкой ресурса сначала восстановите ссылку; аварийная копия только со ссылками не заменяет переносимую копию с изображениями и звуком.

Закройте редактор и установите новую версию. Не удаляйте папку хранилища или исходные проекты для «чистой установки». Для переезда на другой диск используйте «Хранилище редактора» в программе: исходная копия при этом сохраняется.

Новые проекты формата 8 не следует открывать в более старом редакторе. Откат установщика не является откатом формата данных: для возврата используйте резервные копии, сделанные до обновления. Установка и обновление на отдельной чистой Windows ещё не прошли полную приёмку; эта версия остаётся бетой.

## Открыть пример

1. Скачайте `tea-adventure.vnproject` из релиза.
2. На главной нажмите «Открыть проект» и выберите файл. В переносимую копию уже включены изображения.
3. Нажмите «Запустить», осмотрите припасы и пройдите NPC, карту, крафт и учебную встречу.
4. Для собственного проекта нажмите «Новый проект». Набор примера автоматически не добавляется.

Готовая игра — отдельный `tea-adventure-win.zip`. Распакуйте архив в новую папку целиком и запустите находящийся внутри EXE. `.vnproject` предназначен для редактирования, ZIP — для прохождения без редактора.

## Руководство и ошибки

Скачайте `Istoriya-0.2.34-Manual.zip`, распакуйте и откройте PDF либо HTML в браузере. HTML работает без сети; поиск — Ctrl+F. В руководстве 39 разделов с конкретными действиями и скриншотами.

Основное руководство сохранено без переименования. Дополнение про входы глав, группу «Вне глав» и перенос сцен — в [инструкции 0.2.38](releases/0.2.38.md#работа-с-главами-и-сценами).

При проблеме откройте «Диагностика редактора» на главной или в настройках. В обращении укажите версию, последовательность действий, ожидаемый результат и приложите технический отчёт. Не прикладывайте весь профиль, ключи или личный проект без необходимости. Если изменения не сохраняются, сначала сделайте резервную копию через предложенное программой действие; не удаляйте хранилище.
