# План завершения Rust движка

Цель от 23 октября 2026: весь ранее согласованный no-code конструктор новелл и 2D-приключений с полноценным Rust-ядром. Принятая поставка 0.2.34 не объявляется завершением разработки. Все пункты [матрицы ТЗ](MVP_ACCEPTANCE.md) и [общего плана](PRODUCTION_PLAN.md) остаются обязательными.

## Архитектура

Авторский проект со стабильными ID остаётся источником истины. Нативное ядро принимает документ, проверяет его, строит промежуточное представление истории и выпускает самостоятельную игру. React остаётся no-code интерфейсом. Целевой собственный проигрыватель реализуется на Rust; Ren’Py сохраняется как совместимый экспорт/runtime для существующих проектов и игр, но не подменяет завершённый Rust-runtime. Перенос не означает отмену настроек игры, старого монтажа, сохранений, слоёв, игровых систем или пользовательской графики.

## Последовательность переноса

| Этап | Реальная замена | Проверка завершения |
| --- | --- | --- |
| R1 Сборочный конвейер | Rust управляет официальным GUI-генератором, процессами SDK, lint, упаковкой, ключами Android и выдачей свежего пакета. Node временно только генерирует исходники | Реальный EXE → Windows ZIP → обычный старт и ветви/Save/Load; ошибка, таймаут, traceback при exit 0 и старая папка с пакетами не дают ложного успеха |
| R2 Документ и диагностика | Версионированная Rust-модель, структурные/ссылочные проверки, миграции, диагностические сообщения с адресом объекта; старые проекты не теряют поля | Общий корпус schema 1–8, ошибки, русские сообщения, импорт/сохранение/повторное открытие; сравнение со всеми текущими правилами |
| R3 План истории | Типизированные назначения глав/сцен, выборы, условия, реакции, последовательное/временное исполнение, камера и трансформации | Сравнение промежуточного представления и конечного поведения на старых проектах, плотных графах, отрицательных координатах и одновременных событиях |
| R4 Игровые правила | Условия/результаты, инвентарь, отношения, здоровье/навыки/опыт, крафт, NPC/бой и сохраняемое состояние в Rust; единый источник правил предпросмотра и экспорта | Ветви, атомарные результаты, Save/Load/Rollback и несовместимые сохранения; никакого выполнения пользовательского кода |
| R5 Генераторы игры | Rust выпускает сценарий, 11 экранов UI, стили текста, галерею, звук, анимации и настройки; материализует ресурсы | Паритет всех существующих сценариев, медиа и геометрии; затем удаление Node из обязательной нативной поставки и проверка EXE без node.exe |
| R6 Собственный Rust runtime | Самостоятельный проигрыватель 2D-сцен, текста/шрифтов, UI, аудио, движений/эффектов и игровых правил из общего промежуточного представления, без Node/Python; Ren’Py-экспорт сохраняется для совместимости | Игра из редактора запускается на целевой Windows без редактора, Node, Python и SDK; все поддержанные механики/ввод/сохранения проверяются на обоих backend. Старые Ren’Py saves не объявляются совместимыми с новым форматом без отдельного безопасного переноса |
| R7 Полнота конструктора | Закрытие всех оставшихся возможностей исходного ТЗ и пользовательских уточнений | Для каждой строки матрицы есть реальный авторский путь, сохранённый проект и экспортированное поведение, не только наличие формы |
| R8 Production | Большие проекты/ресурсы, длительная работа, физические устройства/DPI, чистая Windows, установка/обновление/откат, подпись, документация | Независимые результаты на целевых системах; ни unit-тесты, ни упаковка не заменяют эти проверки |

Результаты каждого этапа добавляются после фактического выполнения. Непройденный этап не переименовывается в завершённый «ограниченный MVP».

В R1 реализуется жизненный цикл Ren’Py-preview 0.2.36: удержание собственного зарегистрированного проекта до выхода игры, безопасная очистка, восстановление после перезапуска и сохранение локального зеркала `game/saves` вне кэша. Неоднозначные аварийные регистрации и старые неизвестные каталоги не удаляются. Проверки и ограничения — [в отчёте 0.2.36](RELEASE_0.2.36.md). Это не отменяет оставшуюся платформенную приёмку R1 и не закрывает R2–R8.

## Оставшиеся функции

В 0.2.37 начат R2: независимый `istoriya-core` читает документ без переписывания исходных полей, выполняет структурные проверки прежнего `project-format` (включая UI и ключевые кадры) и возвращает адрес объекта. Реальные native build/preview используют эту модель. Корпус из 1320 документов проверяет совпадение принятия/отказа с JS, неизменность принятого JSON и 11 точных адресов ошибок. Ссылочная семантика, миграции и промежуточное представление остаются открытыми; R2 целиком не закрыт.

Матрица сохраняет исходные требования к проектам/ресурсам, сценам/главам/ветвям, отношениям/условиям, анимациям/атмосферным эффектам, аудио/озвучке, полностью настраиваемому игровому UI, сохранениям/автосохранению, локализации, отладке, диагностике, клавиатуре, доступности и производительности. Добавленные пользователем интерактивные предметы, инвентарь, камера/ключи, игровые показатели, крафт, локации/NPC/противники и готовые послойные наборы входят в ту же цель.

Стартовое навязчивое обучение и секундная трактовка новых диалоговых кадров отменены последующими прямыми указаниями пользователя; руководство доступно отдельно. Старые timed-сцены сохраняют свою семантику. Новая история остаётся пустой, набор добавляется явно.

## Состояние разработки

0.2.35 опубликована как бета. Windows-часть R1 подключена к реальным build/preview и проверена в EXE: 322 JS/50 Rust/4 Sites, отключение старого Node-builder/GUI-launcher, свежий ZIP/повтор без перезаписи/ошибочный проект, реальные камера/RPG и UI Build. В готовых играх суммарно 6 сценариев/40 утверждений и два обычных старта; отдельное native preview дошло до настоящего главного меню, а постоянные данные сохранились между двумя сгенерированными заданиями. Новый проект пустой и до, и после сборки, библиотека повторно прочитана в новом процессе. Точные артефакты/границы — в RELEASE_0.2.35.md. Локальная 0.2.36 продолжает жизненный цикл предпросмотра. Android/JDK/ключи, Linux/macOS и обычные системные диалоги ещё не приняты. Генератор сценария пока JS, собственный Rust-проигрыватель ещё не реализован, поэтому полный Rust-перенос **не завершён**. Релизы 0.2.34 и 0.2.35 не заменяются автоматически.
