# 0.2.16 — предмет, голос и звук в одном действии автора

15 октября 2026. Проверяемая бета; полная production-приёмка по ТЗ не завершена.

## Что изменилось

«Предмет» над холстом или ПКМ → «Добавить предмет…» теперь позволяет сразу задать говорящего, звук предмета и озвучку ответа. Можно загрузить MP3/WAV/OGG с проверкой декодирования или выбрать существующую запись, прослушать её и независимо настроить громкость. Записи сначала остаются локальными данными формы: отмена ничего не добавляет, подтверждение создаёт ресурс/предмет/реакцию/инвентарь/шаг осмотра одной операцией Undo. Идентичные записи переиспользуются; явная громкость0 сохраняется. Старые аудиоресурсы без MIME остаются доступны; служебное значение селектора не конфликтует с импортированным ID.

Исправлен реальный runtime-дефект: реакция с голосом, но без текста теперь создаёт отдельный ответ и ждёт нажатия перед переходом к следующей сцене. Голос больше не прикрепляется к следующей посторонней реплике. Пустой ответ поддерживает Save/Load. В preview семантика такая же.

Impeccable использован для узкого улучшения существующего окна: закреплены шапка/закрытие и Cancel/«Добавить на сцену», прокручиваются только параметры. Загруженная запись явно подписана, вместо ложного «Без записи». Graphite/violet-компоновка и остальной редактор не заменялись.

## Доступный игровой цикл без кода

- Отдельные изображения предметов: осмотреть, взять, использовать вещь из инвентаря, скрыть, сменить изображение, ответить персонажем/автором или перейти в сцену/главу.
- Условия доступности и несколько результатов: инвентарь, переменные, флаги, составные правила. Шаг «Осмотреть сцену» действительно ждёт игрока.
- Голос реплик и ответов предметов, звуки действий, музыка/ambience, независимые громкости и остановка каналов.
- Player-state инвентаря/скрытых предметов/реакций сохраняется и откатывается, не изменяя авторский проект.

Это существующие подсистемы с улучшенным общим авторским путём, не заявление, что каждая из них впервые появилась в0.2.16.

## Границы доказательств

Аудиодрайвер runtime QA — dummy; WAV — явно тестовые тоны, не персонажная речь. Подтверждены декодирование/каналы/громкость/жизненный цикл, но не слышимое качество записи. Озвучка импортируется из файлов, микрофонная запись и TTS не добавлялись. Нативные OS-диалоги выбора папки не управлялись: Windows-экспорт выполнен штатным compiler path через ограниченный command-line verifier. Не использовались OS-мышь, переключение рабочего стола, пользовательский профиль или публичная публикация.

Это отдельный предметно-звуковой сценарий. Единая первая игра со всеми пунктами раздела95, lazy-loading больших библиотек, полная DPI/чистая Windows/подпись и остальные пункты MVP_ACCEPTANCE остаются открытыми. Старый timed-монтаж не превращён в интерактивный автоматически.

Два промежуточных установщика сохранены под `QA/candidates/`, не считаются финальной поставкой. Первый выявил скрывающиеся кнопки и подпись записи; второй сохранён до compatibility-коррекции. Их функциональные проверки не подменяют финальный native/export gate.
