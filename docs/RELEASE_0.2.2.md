# 0.2.2 — история без копий ресурсов

Локальная бета от 15 октября 2026. Это шаг к production, не заявление о выполнении всего ТЗ.

## Изменения

- Undo/Redo хранит прямые и обратные изменения, а не 50 полных копий проекта с изображениями. Неизменённые ресурсы и сцены разделяют память. Неизменившее значение поле не добавляет шаг истории.
- Сохранены лимит 50 действий, сброс Redo после новой ветви, отмена удаления/перестановки и совместимость старого монтажа. Формат `.vnproject` не изменён: история не записывается внутрь файла.
- Черновик сериализуется после 250 мс покоя вместо каждого символа. Он проходит реальный `flush` в хранилище. Явное сохранение, закрытие и смена проекта ждут записи; очередь исключает возврат устаревшего черновика после сохранения.
- Транзитивная зависимость source-map-js обновлена до 1.2.2: исправление [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q). `npm audit --omit=dev`: 0 на дату проверки.

## Измерение истории

Один локальный прогон до/после: Node 24.13.1, 500 сцен, 5000 реплик, синтетическая строка ресурса 8 МиБ, 25 изменений одной реплики, принудительный GC до/после. Исходный ресурс не является настоящим PNG: проверяется память и редактирование данных, не декодирование графики. Это не замер всего интерфейса, диска, старта Rust или Ren'Py.

| Метрика | Полные копии | История изменений |
| --- | ---: | ---: |
| Медиана изменения | 9,06 мс | 0,14 мс |
| p95 изменения | 12,64 мс | 1,25 мс |
| 25 изменений суммарно | 244,76 мс | 9,32 мс |
| Удержанная дополнительная heap-память | 250,20 МиБ | 0,26 МиБ |
| 25 отмен суммарно | 2,59 мс | 3,96 мс |

Undo теперь применяет обратные изменения и в этом прогоне немного медленнее простого переключения ссылки. Выигрыш — отсутствие полных копий и быстрая правка. Не переносить эти цифры на произвольные проекты.

Скрипт: `node --expose-gc scripts/benchmark-history.mjs .artifacts/performance/history-after.json`. Исходные замеры сохранены в `.artifacts/performance/history-before.json` и `history-after.json`.

## Что ещё не доказано

Полное прохождение собранной игры, save/load/rollback, все обязательные сценарии MVP, чистая Windows, DPI, обновление/откат и доступность ещё требуют приёмки. Большая библиотека по-прежнему сериализуется при сохранении; масштабируемое файловое API и ограниченные подписки компонентов остаются работой этапа 3. Авария в пределах 250 мс после последнего ввода может потерять этот последний короткий пакет правок; до записи черновика данные находятся в памяти. Не объявлять эту версию завершённым production.

Механизм основан на документированных [прямых/обратных patches Immer](https://immerjs.github.io/immer/patches/), а не на копировании проекта после каждого события.
