# Проверка обязательного MVP

| № | Требование ТЗ | Реализация и проверка |
|---:|---|---|
| 1 | Создание и открытие проектов | Главная страница, мастер проекта, локальная библиотека и `.vnproject` |
| 2 | Русский интерфейс | Все авторские рабочие пространства и сообщения на русском |
| 3–6 | Ресурсы, фоны, персонажи, спрайты | Импорт, drag-and-drop, метаданные, использования, глобальная замена, защищённое удаление |
| 7–8 | Визуальная сцена и слои | Перетаскивание, направляющие, масштаб, поворот, отражение, прозрачность, видимость, блокировка и порядок |
| 9–11 | Диалог, автор, выбор | Визуальные блоки, озвучка, результаты и условия отображения вариантов |
| 12–15 | Главы, сцены, переходы, карта | Создание, переименование, удаление, порядок, реальные связи, drag/zoom и переход по двойному щелчку |
| 16–18 | Переменные, флаги, условия | Типы число/текст/да-нет/отношения; операции и ветвление без выражений кода |
| 19–21 | Музыка, звуки, озвучка | Ресурсы, громкость, повтор, fade и привязка голоса к реплике |
| 22–23 | CG и галерея | Показ/скрытие CG, разделы, карточки, постоянная разблокировка после просмотра |
| 24–25 | Анимации и Fade/Flash/Shake | Появление, движение, смена спрайта, прыжок, пульсация, тряска и переходы |
| 26–28 | Диалоговый UI, импорт UI, главное меню | Собственные изображения, позиция, цвета, размеры, кнопки выбора и состав меню |
| 29–30 | Save/Load и история | Стандартные проверенные экраны Ren’Py с ручными/автосохранениями и историей реплик |
| 31–32 | Предпросмотр и запуск со сцены | Быстрый просмотр плюс компиляция и запуск настоящего Ren’Py runtime с выбранной сцены |
| 33–34 | Автосохранение и Undo/Redo | Настраиваемый интервал, аварийная копия, 50 шагов истории и горячие клавиши |
| 35 | Проверка проекта | Кликабельный отчёт; ошибки блокируют сборку |
| 36 | Windows x64 Build | Ren’Py lint и самостоятельный ZIP с `.exe`; игроку не нужен Python или Ren’Py |

Дополнительно работают Linux x64, macOS Universal, Android APK/AAB, постоянный Android-ключ подписи, иконка игры и пользовательский курсор.
