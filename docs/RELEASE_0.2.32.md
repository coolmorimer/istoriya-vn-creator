# 0.2.32 — локальная запись, затухания и проверки выпуска

16 октября2026. Локальный кандидат беты, не завершение полного ТЗ.

## Изменения

- В свойствах озвучки/звука — «Записать». Микрофон запрашивается только явным нажатием. Разрешение, запись, обработка, сохранение и отмена имеют отдельные состояния. До120 секунд; ограничены также объём и формат. Запись локальная, без отправки в интернет; результат — настоящий моно PCM16 WAV. Отказ/отсутствие/занятость микрофона объясняются по-русски. Поздний ответ после отмены, смена выбранного действия и закрытие формы освобождают поток; черновик не добавляется в проект до подтверждения. Используются общие decode/attach/Undo правила. Это не TTS и не обработка актёрской речи.
- Встроенный preview воспроизводит fadeIn музыки и fadeOut остановки каналов. Нулевая громкость микшера остаётся нулевой; изменение настроек не перезапускает трек/затухание. Завершённый одноразовый звук не запускается заново из-за другого render. Плееры/таймеры/обработчики освобождаются при закрытии, замене и ошибке. Stop-команды и настенные часы не записываются в тестовые сохранения. «Плавное начало» музыки доступно в инспекторе.
- Основной JSON и `.bak` теперь отдельно подготавливаются во временных файлах и синхронизируются перед заменой. Резервная версия больше не перезаписывается простым fs::copy с риском частично записанного backup. Сохранены защита read-only/повтор и совместимость старых JSON. Это не транзакция сразу нескольких внешних файлов и не гарантия power-loss на любом носителе.
- `npm run verify:release`: воспроизводимая проверка фактического native EXE — bundle, Rust Save/reopen, Windows Build, обе ветки, игровой FileSave/FileLoad и отдельный обычный запуск ZIP. В GitHub workflow добавлены Rust/EXE/runtime проверки. Отдельная hosted-only проверка предназначена для реального установщика: опубликованная0.1.1 с проверкой SHA → кандидат → обычный UI с миграцией фикстуры schema2 → повторная установка → удаление без потери профиля/внешнего проекта. Скрипт запрещён на локальном ПК и требует ephemeral GitHub-hosted runner. Его подготовка не считается успешным remote run.

Rust проверяет обработанные ошибки на четырёх границах primary/backup commit, полный fallback и отказ замены backup. Эти injected-return тесты не являются физическим отключением питания. Native сохранение/закрытие двух процессов завершились0; новый процесс действительно воспроизвёл сохранённую запись.

Сохранены отрицательные QA-попытки: ожидание видимости скрытого option вместо attached; чтение coalesced storage сразу после Undo; неверное ожидание громкости1 при авторских0,8; bytes-литерал, не принимаемый parser тестовых команд Ren’Py; отсутствие teardown в первой smoke-фикстуре. Исправлены тестовые условия, не подавлены ошибки продукта. Последний PASSED-first timeout не засчитан. Отдельно сохранён отказ сборки по заполненному E:.

Кэш `src-tauri/target/release` перенесён на D: после SHA-сверки9456 файлов и заменён junction; сохранены все байты, исходники/проекты/релизы не удалялись. Это организация локальной сборочной машины, не изменение папки пользователя продукта. Исходники компилируются и на обычном runner без этой ссылки.
