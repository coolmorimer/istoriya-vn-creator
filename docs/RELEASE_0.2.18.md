# 0.2.18 — применение вещей из инвентаря

16 октября 2026, локальная проверяемая бета. Направление — no-code движок интерактивных новелл, не заявление о готовности универсального RPG-движка.

## Что изменилось

В инвентаре игрока появилась кнопка «Применить: …» и список доступных целей текущей сцены. Цели — существующие реакции предметов с требуемой вещью либо результатом её изъятия. Второй скрытой логики нет: условия, количество, одноразовость, скрытие слоя, текст/голос/SFX, результаты и переходы выполняются теми же реакциями, что и при нажатии на предмет на сцене. Проверка повторяется при исполнении. Состояние выбора цели не пишется в авторский проект или тестовые сохранения.

Если целей нет, preview объясняет это. Цели не появляются поверх CG, вне осмотра, при нехватке количества, после одноразовой реакции или для скрытого предмета. Требование вещи само по себе её не расходует; расход задаётся результатом «Использовать предмет инвентаря». В Ren'Py инвентарь возвращает цель в существующий осмотр через [документированные Hide/Return actions](https://www.renpy.org/doc/html/screen_actions.html#Return), затем исполняется проверенная реакция. Текст названий/описаний/кнопок экранируется, а не исполняется как подстановка Ren'Py.

В свойствах шага точка входа стала называться «Добавить звук к действию», а при существующей записи — «Звук действия · запись добавлена» с открытыми настройками. Само прикрепление SFX к действиям, голос к репликам/ответам, загрузка MP3/WAV/OGG и четыре канала уже существовали; не выдаём их за вновь созданные функции. Нового TTS или записи микрофона здесь нет.

Impeccable использован для точечного Operate-улучшения инвентаря и заметности аудио, без перестройки graphite/violet оболочки. Переносимый формат остаётся schema6: никаких обязательных новых полей, потребления по умолчанию или скрытого преобразования старых сцен.
