# 0.2.3 — персонаж прямо в кадре

Локальная бета от 15 октября 2026. Общий production-MVP остаётся незавершённым; этот выпуск закрывает конкретный авторский путь и связанные ошибки.

## Пользовательский путь

«Добавить персонажа» над холстом → «Новый персонаж» → имя, изображение, название спрайта, начальное положение → «Создать и добавить».

В пустом проекте форма нового героя открывается сразу. Она не уводит на другую страницу и не требует внутренних имён или команд. Герой, основной спрайт, ресурс и появление в выбранном кадре создаются одним шагом Undo. Изменения применяются только при подтверждении; отменённая загрузка не оставляет пустого героя или неиспользуемый ресурс.

Можно выбрать изображение из ресурсов вместо повторной загрузки. У существующего героя без спрайта карточка предлагает загрузить изображение в той же форме. Для старой временной шкалы новый герой добавляется клипом в точку вызова меню; добавление с холста timed-сцены сохраняет прежнюю семантику постоянного слоя.

## Исправления

- При открытии последовательной сцены выбирается её первый шаг: автор не видит пустой начальный холст, когда первым действием является появление героя.
- Undo/Redo создания героя возвращает выделение; удалённые действия и объекты не остаются ложным выделением.
- Битые, пустые, неподдерживаемые файлы и файлы больше 100 МБ отклоняются. PNG/WebP/JPEG реально декодируются; прозрачность не преобразуется. Поля формы сохраняются после ошибки, поздний ответ загрузки не перезаписывает новый выбор.
- Фокус остаётся в форме, Tab/Shift+Tab циклически обходят её элементы, Escape закрывает. Клавиши формы не удаляют/отменяют объекты под ней.
- Холст и preview получили локальный stacking context: его кнопки и текст больше не выступают поверх модальных форм.
