# 0.2.9 — интерактивные предметы и звуковое сопровождение

Проверяемая бета. Реализовано ядро взаимодействий для новелл; это не заявление о готовности универсального игрового движка или всего ТЗ.

## Работа автора

1. «Предмет» над холстом добавляет независимое изображение. Выберите предмет на холсте или в слоях, затем «Свойства → Взаимодействия».
2. «Добавить реакцию»: название кнопки, ответ, говорящий, результат. Доступны осмотр, взятие в инвентарь, использование предмета с расходованием количества и скрытие.
3. Для взятия автоматически создаётся предмет инвентаря. Его название, описание, количество и иконка редактируются. В дополнительных настройках — одноразовость, требуемый предмет/флаг, включение флага, новое изображение, переход к сцене или входу главы.
4. Добавьте шаг «Осмотреть сцену». Во время него игрок нажимает предметы; продолжение можно ограничить наличием предмета и/или включённым флагом. Секундные сцены не конвертируются автоматически; осмотр в timed-режиме отклоняется проверкой.
5. Озвучка загружается непосредственно в реплику, текст автора или ответ предмета. SFX можно прикрепить к предмету и действию. MP3/WAV/OGG проверяются реальным декодированием, есть прослушивание и ошибки повреждённых файлов. Доступно переиспользование ресурса без дубликата. Это загрузка записей, не синтез речи.

Настройки предметов находятся контекстно справа; дополнительные условия раскрываются отдельно. Impeccable использован для сохранения существующей графитово-фиолетовой компоновки, фокуса и читаемых русских подписей, без редизайна. Обзор 1440×940 и 1000×700 не обнаружил горизонтального переполнения; на узком окне обе боковые панели всё ещё уменьшают холст.

## Исполнение

- Инвентарь, скрытые предметы, использованные реакции и сменённые изображения — состояние игрока, не изменения проекта. Поддерживаются Save/Load/Rollback и сохранение состояния между сценами.
- Предметы сохраняют слой и трансформацию. В Ren'Py они заменяются интерактивным экраном на прежнем master-теге с восстановлением порядка; область нажатия учитывает альфа-канал. Использованы публичные screen API установленного SDK8.5.3, сопоставленные с [документацией Ren'Py](https://www.renpy.org/doc/html/screen_python.html).
- Проверка проекта отклоняет битые ссылки, повторные ID предметов/реакций, отсутствующие аудиофайлы и осмотр под перекрывающим CG. Удаление используемых сцен, говорящих, переменных и флагов защищено.
- Формат проекта — schema3. Старые schema1/2 читаются; интерактивные проекты требуют редактор0.2.9+. Старый редактор должен отклонить их, а не молча потерять механику.
