# 0.2.6 — анимации, сохраняющие состояние персонажа

Локальная бета, 15 октября 2026. Продолжение MVP, не заявление о готовности всех функций ТЗ.

## Исправлено

Восемь пресетов — дрожь, сильная дрожь, прыжок, подпрыгивание, пульсация, увеличение, шаг вперёд и назад — используют общий план движения. Экспорт больше не сбрасывает масштаб к 100% и не выбирает основной спрайт вместо текущей эмоции. Сохраняются положение, поворот, прозрачность и отражение. Дрожь локальна для героя, не вызывает экранный hpunch/vpunch.

В последовательной сцене анимационный шаг длится указанное время, затем переходит к следующему с явным конечным состоянием. В timed-сцене он остаётся неблокирующим. Шаги вперёд/назад умножают текущий масштаб и сохраняют его в следующих шагах; остальные пресеты заканчиваются исходным размером/положением. Выбор последующего кадра показывает этот итог. Правка масштаба на таком кадре учитывает унаследованный множитель вместо повторного увеличения.

Preview действительно проигрывает анимации через Web Animations API. Кривая — линейные отсчёты той же cosine ease, что используется ATL; это не утверждение о побитовом совпадении двух рендереров. Задействована [официальная ATL-интерполяция Ren'Py](https://www.renpy.org/doc/html/transforms.html#interpolation-statement), поведение дополнительно проверено на установленном 8.5.3.

Увеличенный/повёрнутый герой больше не перекрывает кнопку «Далее»: игровое preview обрезается границами кадра. **Холст редактора не обрезан** — возможность размещения за сценой сохранена. Из примера убраны добавленные ранее технические дубли пауз после анимации; пользовательские паузы в других проектах не меняются.

## Границы

Рабочий стол мышью/клавиатурой не управлялся; Ren'Py запускался на отдельном тестовом desktop, Chromium — headless. Звук через dummy не прослушивался. Все варианты пересечения и прерывания старых timed-клипов, редактирование в середине их анимаций, resize окна во время движения и сохранение/rollback в каждой промежуточной фазе ещё не приняты. Эти ограничения не подменяются успешным тестом одной timed-пульсации. Нет новой приёмки чистой Windows/разных DPI/обновления/отката. Компилятор остаётся JS worker в Rust-оболочке; неподтверждённое ускорение не заявляется.

Impeccable использован для функционального предпросмотра в существующем интерфейсе и изоляции игрового содержимого от управляющих кнопок. Общий production-MVP остаётся активной работой.
