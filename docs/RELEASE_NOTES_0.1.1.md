# История 0.1.1 — предварительный выпуск

Для установки скачайте **Istoriya-Setup-0.1.1-x64.exe**. Это полный установщик Windows 10/11 x64: редактор, Ren'Py, Python, ярлыки и деинсталлятор. Отдельно ставить Node.js или Ren'Py не требуется.

Установка выполняется для текущего пользователя. Проекты не удаляются при деинсталляции. Перед обновлением делайте резервные копии.

Изменения: основной спрайт и имена состояний персонажа, добавление на сцену, перемещение мышью без скачков, угловые маркеры размера, сохранение трансформаций клипов.

Проверено: 40 автоматических тестов, установка/удаление, сборка Windows-игры установленным SDK. Это предварительная версия с известными ограничениями, описанными в README и PRODUCT_AUDIT.md. Android требует дополнительной настройки Java/SDK.

**Установщик без цифровой подписи.** Проверяйте скачанный файл по прилагаемому SHA256SUMS.txt. Исходники публичны; открытая лицензия на оригинальный код пока не выбрана владельцем. Сторонние лицензии включены.
