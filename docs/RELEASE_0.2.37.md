# Проверка Истории 0.2.37

Бета для Windows x64 от 23 октября 2026. [Файлы и установка](releases/0.2.37.md). В поставку входят структурное Rust-ядро документа и изменения жизненного цикла предпросмотра из [0.2.36](RELEASE_0.2.36.md).

## Rust ядро документа

`crates/istoriya-core` не зависит от Tauri, Node или Python. Модель заимствует исходный JSON и предоставляет типизированные представления сцен, глав и действий. Проверка не переписывает пользовательские поля, не материализует медиа и не мигрирует документ при чтении. Принимаются прежние форматы 1–8 с исторической нормализацией метаданных версии.

Перенесены структурные правила прежнего `runtime/project-format.mjs`: списки, ID, действия, эффекты и условия, определения предметов и RPG-объектов, 11 экранов игрового UI, цели и ключевые кадры движения. Диагностика содержит JSON-pointer для разработчика и русское сообщение с контекстом сцены/шага для пользователя. Незавершённые авторские ссылки по-прежнему могут храниться как черновик; структурная проверка не объявляется доказательством проходимости истории.

Реальные native build/preview вызывают Rust-проверку до подготовки SDK. Внутренний JS-worker принимает отдельный фиксированный `document.json`, сверяет длину и SHA-256 и генерирует исходники без старого JS-структурного валидатора. Публичный JS-компилятор для совместимого пути проверку сохраняет. Контрольная сумма обнаруживает повреждение передачи, но не аутентифицирует процессы от злоумышленника того же пользователя.

## Фактический EXE и игры

- В собственной копии EXE отключены старый JS-builder, JS GUI-launcher и JS-структурный валидатор. Сборка, повторный свежий ZIP и готовая игра проходят через Rust-конвейер.
- Неверный тип действия отклонён до генератора исходников. Изменение переданного JSON той же длины отвергнуто; предыдущие ZIP сохранили свои SHA.
- Реальная кнопка «Собрать для Windows» создала игру с авторским текстом. В этой игре проверены текст, Save/Load и отдельный обычный запуск без тестовых аргументов.
- В остальных готовых играх проверены ветвление с Save/Load, RPG-системы и геометрия/завершение камеры и ключевых кадров. Итого 6 сценариев, 40 утверждений и 2 обычных запуска; исключений runtime нет.
- Два отдельных native-preview достигли настоящего главного меню и вышли с кодом 0. После каждого подтверждено удаление staging, сохранность основного persistent и дополнительного локального зеркала вне кэша; второй запуск прочитал данные первого.
- Новый проект после сборки не содержит ресурсов, персонажей, предметов или действий; RPG выключен. Сохранённая библиотека проверяется в новом процессе приложения.

Проверки выполняются на собственных QA-копиях и отдельном Windows desktop без переключения рабочего стола или OS mouse input. Данные владельца не меняются. Звук тестируется с dummy-драйвером: это не проверка слышимого качества озвучки. Диалог выбора папки в UI-сборке заменён ограниченным QA-выходом, поэтому обычные системные диалоги не приняты этим прогоном.

Первый повторный запуск JS-тестов пересёкся с SDK-проверкой и получил конфликт служебного persistent launcher. Полный последовательный повтор прошёл. В одном QA-наблюдателе не учитывался верхний регистр временного ID; закрыта только собственная тестовая игра, наблюдатель исправлен, два свежих прогона прошли. Эти результаты не засчитаны как успешные прогоны до повторной проверки.

## Установщик и публикация

Inno Setup собрал `Istoriya-Rust-Setup-0.2.37-x64.exe` из проверенного EXE. Сверены версия, встроенный UI, runtime и SHA бинарника до/после упаковки. Bootstrapper WebView2 имеет проверенную подпись Microsoft. Сам установщик Истории пока не подписан.

Состав, коммит и SHA-256 находятся в публичных `release-manifest.json` и `SHA256SUMS.txt`. Руководство PDF/HTML и послойные примеры перенесены без изменения байтов из прежней поставки; сохраняют исходную версию 0.2.34. Личные проекты, SDK-кэши, профили QA, ключи и журналы в Git/Release не входят.

Установка и обновление на чистой Windows не проверены этим прогоном; GitHub Actions не засчитывается как успешная приёмка. Ссылочная семантика, миграции, план истории, игровые правила и генераторы ещё не полностью перенесены на Rust; собственного Rust-проигрывателя пока нет. Полная production-приёмка, Android и другие платформы остаются в [общем плане](RUST_ENGINE_PLAN.md).
