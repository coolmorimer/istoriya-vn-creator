## Единый сценарий раздела95 — ограниченно подтверждён в0.2.17

С главной создать пустой1920×1080 проект → импортировать фон → создать героя с PNG-эмоциями → создать сцену → поставить героя на холсте → реплика → музыка → появление → выбор → связать две сцены → собственное окно диалога → preview → Windows Build → пройти обе ветки/save/load → открыть portable-проект заново.

**Одна непрерывная текущая native-проверка без импорта готового .vnproject выполнена**, см. A17. Portable проверен отдельно после полного перезапуска; сохранение на выборе совместимо. Пользователь запретил управление его мышью: QA — в отдельном WebView/профиле, без OS input и без переключения input-desktop. При UI-сборке папка автоматически ограничена этим QA-профилем; импорт portable использовал реальный HTML file-input handler, не OS file-picker. Обычные диалоги выбора файлов/папок и все конфигурации Windows остаются непроверенными. Это не полная приёмка всех36 пунктов.

## Остальная исходная область цели сохраняется

- Настраиваемые предметы/инвентарь/реакции и озвучка имеют R/T-доказательства; камера и ключи трансформаций предметов реализованы M33. Все текстовые/атмосферные эффекты, скелетная анимация и фрагментное оформление не завершены.
- Свободные панели внутри окна и закрепление к краю реализованы M33. Отдельные системные окна/второй монитор и полная система docking не приняты; это не весь Photoshop-подобный workspace.
- Параллельные сюжетные ветви существуют как связи/условия. Одновременное исполнение нескольких сцен не обещается и не доказано.
- L22 проверяет реальный интерфейс и экспорт500 сцен/5000 шагов/5000 небольших файлов. Не проверены холодный диск, пиковая RAM, большие изображения, вся карта/все селекторы и длительная работа. P19 устранил full-hydrate: компактные ссылки при load, старый`.bin` читает максимум1024 байта сигнатуры. Старый base64 JSON и внешний portable autosave остаются отдельными затратами. Эти локальные замеры не выдаются за общий запуск/FPS/RAM или всю performance-приёмку.
- Rust — оболочка/хранилище/процессы; JS-компилятор пока встроенный worker. Полный Rust-порт компилятора не завершён; измеренных общих ускорений не заявляем.
- Нужны DPI100/125/150/200%, FullHD/2K/4K, остальные отказы диска и миграции с копиями, визуальный перенос профиля. Базовый журнал реализован D30; обычные clipboard/Explorer, power-loss/minidump и весь release-gate не приняты. Общий relink ограниченно подтверждён M21; read-only/recovery — P19/C23. Это не все повреждения/отказы носителя, сбой питания внутри commit или весь набор кодеков.
- Чистая Windows, upgrade/rollback и коммерческая подпись не приняты. Отсутствующие ключи/сертификаты и внешние публикации не выдумываются.
- Сценарий/portable-художественный пример сохранены. Новых сгенерированных иллюстраций и актёрской озвучки в этой итерации нет; QA-прямоугольники не выдаются за готовую игру.

Итог: расширения0.2.13–0.2.30 и сквозной сценарий A17 двигают цель вперёд, но полный production-MVP и весь исходный запрос пока **не подтверждены**.
