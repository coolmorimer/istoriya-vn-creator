# 0.2.26 — поиск по проекту и точное место редактирования

16 октября 2026. Локальная проверяемая бета, не завершённая production-приёмка.

## Изменения

«Найти в проекте» в верхней панели и Ctrl+Shift+F открывают поиск глав, сцен, текста реплик/выборов, предметов и реакций, героев и именованных спрайтов, файлов, инвентаря и галереи. Поиск учитывает регистр и ё/е, показывает контекст главы/сцены и фрагмент текста. Это не fuzzy-поиск и не поиск в содержимом медиа. Одновременно смонтировано максимум8 результатов; Home/End/стрелки/страницы/Enter достигают остальных. Escape закрывает поиск, фокус остаётся внутри диалога; модифицированные клавиши редактирования не перехватываются.

«Где используется» в библиотеке больше не обрезается первыми8 ссылками: все использования доступны через поиск/страницы, кнопки начала/конца. Действия подписаны номером шага и текстом. Ссылки сохраняют конкретную реакцию, спрайт, раздел и изображение галереи. Прямой переход к ресурсу снимает старый фильтр, который иначе мог скрыть результат.

Единый editorNavigation проверяет текущий проект и ссылки перед одним transient-обновлением состояния. Переход открывает нужный шаг и его инспектор, для старого монтажа — реальный playhead; раскрывает скрытые свойства/кадры. Поиск/навигация не изменяют проект и Undo. Битая ссылка показывает ошибку, а не выбирает первый объект. Карта глав выбирает нужную главу; галерея — правильный раздел. Использования инвентаря тоже используют этот путь.

Реальный native-тест обнаружил, что TimelineEditor после правильного перехода сбрасывал playhead на0 при mount. Сброс перенесён в смену сцены в store; повторное открытие панели сохраняет точное положение. Новый/открытый проект начинает с0. Поле назначения теперь явно называет очистку «Убрать переход»; для неявной связи карты не показывает очистку без результата — её удаляют отдельной командой.

Impeccable использован для компактного поиска с читаемым контекстом, ограниченным списком и фокусом в существующей graphite/violet теме. Нового обучения/каталога шаблонов нет.

## Ориентиры

- [Twine: Navigating the Story Map](https://twinery.org/reference/en/editing-stories/navigating.html) — быстрый поиск по имени/содержимому с клавиатурным открытием. Автор по-прежнему не пишет ссылки или код.
- [Godot: Default editor shortcuts](https://docs.godotengine.org/en/4.6/tutorials/editor/default_key_mapping.html) — идея отдельного быстрого поиска. Страница предупреждает об актуальности для4.6; её сочетания клавиш не выдаются за гарантию текущей версии. В «Истории» выбрано Ctrl+Shift+F.

## Оставшиеся ограничения

Полное дерево500 сцен/плотная карта пока не виртуализированы. Поиск синхронно строит лёгкий индекс метаданных при открытии; многогигабайтные медиа/RAM/cold-диск не измерены. Встроенный preview не равен полному Ren’Py по всем timed/animation/fade сценариям. Чистая Windows, вся DPI/upgrade/rollback матрица, коммерческая подпись, микрофон/TTS, произвольные RPG-мини-игры, physics/keyframes, полный docking и Rust-порт компилятора не завершены. Полная цель и все gates PRODUCTION_PLAN/MVP_ACCEPTANCE сохраняются. Новых иллюстраций или актёрской озвучки нет; технические прямоугольники — не художественная игра.
